# Genshin-Impact-Lv60

![Genshin Impact Poster](poster.png)

Starting Life in a Gacha World, But I'm already Lv. 60! 🎮✨

## Sobre el Proyecto

Esta es una novela ligera (light novel) ambientada en el universo de Genshin Impact. La historia sigue a un protagonista que ha sido transportado a Teyvat y ya posee el nivel máximo — Lv. 60 — pero debe aprender a sobrevivir sin el poder de un Archon.
